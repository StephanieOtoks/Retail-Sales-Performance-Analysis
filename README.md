# Retail Sales Performance Analysis

## Project Overview

This project analyzes retail transaction data to evaluate sales performance, identify revenue trends, and understand customer purchasing behavior. Microsoft Excel was used to clean and organize the data, perform exploratory data analysis, and build an interactive dashboard to support business decision-making.

## Project Objectives

- Evaluate overall retail sales performance.
- Analyze revenue trends across different years and months.
- Compare revenue across product categories and store types.
- Examine sales contributions by gender and customer segments.
- Identify high-value customers.
- Present key performance indicators and findings in an interactive dashboard.

## Tools and Skills

- **Microsoft Excel**
- Data cleaning and validation
- Exploratory data analysis (EDA)
- Excel formulas
- PivotTables and PivotCharts
- Slicers and interactive dashboards
- Data visualization and business insights

## Dataset

The dataset contains retail transaction records, including information on sales, products, customers, store types, transaction dates, quantities, and tax.

The data was reviewed and cleaned before analysis to improve consistency and reliability.

## Data Cleaning

The data-cleaning process included:

- Checking for missing and inconsistent values.
- Reviewing age values and correcting data-quality issues.
- Checking for duplicate records.
- Standardizing data formats.
- Preparing the cleaned dataset for analysis.

## Analysis Performed

The analysis explored:

- Revenue performance over time.
- Revenue by product category.
- Revenue by store type.
- Revenue by gender.
- Customer purchasing patterns.
- Top customers by revenue.
- Key performance indicators, including total revenue, total transactions, total customers, and quantity sold.

## Key Findings

- **Total revenue:** Approximately $54.45 million.
- **Total transactions:** 20,876.
- **Total customers:** 5,506.
- **Total quantity sold:** 62,701.
- **Top-performing product category:** Books.
- **Highest-revenue store type:** e-Shop.
- **Highest-revenue year:** 2012, within the period analyzed.

These findings help highlight the strongest product category, sales channel, and year in the dataset.

## Interactive Dashboard

The Excel dashboard presents the main performance indicators and sales trends in one place. Interactive slicers allow users to filter the analysis by year, month, product category, store type, and gender.

## Business Recommendations

- Review the factors contributing to the strong performance of the Books category and consider applying successful strategies to other categories.
- Investigate the performance of the e-Shop channel to identify opportunities to maintain or improve revenue.
- Examine monthly and annual sales trends to support sales planning and inventory decisions.
- Use customer-level analysis to identify high-value customers and develop appropriate retention strategies.
- Monitor key performance indicators regularly to identify changes in sales performance.

## Conclusion

This project demonstrates the use of Microsoft Excel to transform retail transaction data into meaningful business insights. Through data cleaning, exploratory analysis, and dashboard development, the project provides a clearer view of sales performance across products, store types, time periods, and customer segments.
